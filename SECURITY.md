# Security policy

## Supported version

Only the latest released version is supported during the pilot phase.

## Reporting

Do not file a public issue if a future scan appears to expose an active credential, private endpoint, or personal data. Contact the repository owner privately through the security-reporting channel available on the GitHub repository.

The current dataset is designed not to contain credentials or private data. It stores public repository identifiers, hashes, labels, and short documentation fragments.

## Scope

Documentation defects identified by this research are not automatically security vulnerabilities. The checker does not execute third-party commands or untrusted repository code.
