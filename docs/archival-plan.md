## Preferred preservation sequence

1. Merge the publication and archival documentation after CI succeeds.
2. Record the final `main` commit SHA.
3. Create the annotated tag `research-closeout-issue-121` at that exact commit.
4. Create the GitHub release using the negative-research title and disclosure text.
5. Attach or link the required machine-readable result files and checksum manifest.
6. Connect the repository to Zenodo and archive that tagged release.
7. Record the minted concept DOI and version DOI without modifying historical result files.
8. Update `CITATION.cff` in a metadata-only change with the DOI.
9. Submit the final commit or repository URL to Software Heritage and record the resulting SWHID when available.
10. Optionally mirror the release package and protocol to OSF or an institutional repository.

## Archive descriptions

The abstract must state:

- detector productization was not supported;
- the repository is not a recommended README checker;
- the static evaluation failed preregistered gates;
- dynamic corrections do not rehabilitate detector validity;
- the sample and annotation limitations;
- independent reproduction count was zero at closeout;
- no GitHub Action v0.2 was created.

## Version policy

- The closeout tag is immutable.
- Historical raw attempts, predictions, labels, and result hashes are not rewritten.
- Metadata-only corrections use a new archival version and link back to the closeout tag.
- Independent replication results use distinct study IDs and releases.
- A future detector version requires a new preregistration and dataset; it is not a continuation of the issue-121 evaluation.
